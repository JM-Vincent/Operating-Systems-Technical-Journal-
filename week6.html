The reason why the Request per second and Time per request were not better, because of the resource contention on the host PC. The Nginx connections increased to 1024 increased the memory overhead per connection, inwhich the a resource-constrained VM environment, caused slightly higher latency (Context Switching) rather than improved throughput ).

Performance visualisations

Critical reflection.


In the sixth phase, was the second most challeging. I attempted to tune the server for higher loads, but the results showed a slight performance regression (1440 req/sec down to 1184 req/sec). What I learnt was that simply increasing limits (like connections) increases memory overhead, which can backfire if the underlying hardware (or VM allocation) is constrained. I understood that optimisations is about finding the right balance for the specific hardware available.
