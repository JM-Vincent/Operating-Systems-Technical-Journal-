Distribution selection justification and comparison.

I selected Ubuntu Server 24.04 LTS(long term support) due to the fact that this Linux distribution has a excellent balance of modern features, extensive support and user-friendliness.


Distro justification.

The justification of using my choice of Linux distribution is because of three reasons.
One of those reason is the ease of and community support. Ubuntu is notable for its user-friendliness. The package management system, apt$, is intuitive, and the installation process is straightforward.

Moreover, it boasts one of the most extensive online communities, ensuring the availability of comprehensive documentation, tutorials, and troubleshooting guides. This is a significant advantage for a project environment.

The second reason why I chose Ubuntu is because of the package availability. The Ubuntu repositories are extensive and contain software that is up to date. This allows the straightforward installation and configuration of new services, thus eliminating the need for source complication or the management of sophisticated dependencies.

And last reason why I chose Ubuntu is because of the long term support, which I chose the LTS release of the distro guarantees a stable platform that will receive security updates for a period of five more years. This is similar to a real-world production environment in which stability and security are of the utmost importance.



Distro comparison.

Ubuntu compared to alternative like Alma Linux, Rocky Linux, or Debian is a much better choice. Both Alma Linux and Rocky Linux distros have found been found to exhibit excellent stability and are recognised for their compatibility with Red Hat Enterprise Linux(RHEL), with a one-to-one ratio of compatibility. Theses devices are now considered a standard component in numerous corporate environments. However, it should be noted that the package manager utilised by these distributions, namely (DNF/YUM) is different while the software repositories maintained by these distros are generally stable, they are not as current as Ubuntu's. The accessibilities of Ubuntu ease of use and a large community support were more important.

As for Debian, while it is known that the distro is the 'upstream' distribution for Ubuntu, and that is renowned for its rock-solid stability. However, its stable branch frequently utilises older, more thoroughly tested versions of software. Ubuntu LTS represents a satisfactory compromise by being based on Debian's stable core, yet offering more recent packages.



Workstation choice justification.

The justification of using my choice of workstation option is because of four reasons.

One the reason of my choice of workstation option is because of the Graphical User Interface(GUI). In contrast to the server, which operates in a command-line-only (CLI) mode to conserve resources, the workstation is installed with a comprehensive desktop environment (e.g. GNOME). This distribution is equipped with a range of essential tools for system administrators, including a web browser (for testing a web server), a visual text editor, and various graphical applications.

The second reason is because of the client-side tools, which The workstation is the optimal location for the installation and execution of client-side software. For instance, the virtual machine could be employed to test an SSH connection to the server or to access a database hosted on the server.

The third reason is because of the network segregation which the utilisation of a dedicated workstation virtual machine (VM) facilitates the emulation of a realistic network environment. The administrator does not have direct access to the server; rather, they utilise a network connection, which is widely regarded as a best practice for enhancing security and management.

The last reason is because of resource allocation, which the workstation has been configured in a manner that differs from that of the server. While it may have more RAM allocated to support the GUI, it does not require the same amount of persistent disk space as a server.
