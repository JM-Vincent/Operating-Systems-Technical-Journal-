Week 7: Security Audit and System Evaluation.

Conducting a security audit and evaluate overall system configuration.

Security audit.




First of all, I installed Nmap to scan the the network. After typing the command for scaning the network, the result was only essential ports are open, which both 22/tcp and 80/tcp are open which mean SSH server software is up to date and Nginx is running correctly.

Aslo other ports like 997 tcp port and 443/tcp port are blocked, meaning the UFW firewall is activly blocking connections to all other ports that are common and the server rejected the connection to port 443, due to not setTing up HTTPS/SSL.

The Nmap successfully identified the OS as Linux.


Next I do a security scanning with Lynis. I installed Lynis remotly on the server VM to scan the server for vulnerabilities and find out what the Hardening index is, which was 60.

Then I implemented few changes to make the server have less vulnerabilities to boost up the Hardening index. After rescaning the server, the Hardening index is still, which I then did some changes like securing the bootloader configuration, etc. Now when I rescan the server, the Hardening index becaomes 61.

Finally, I ran a command that would show what is running on the Server VM.

Security service on the server VM

Service name Status Justification
sshd Active Needed for remote administration access.
nginx Active The web server hosting the application.
ufw Active Firewall service required for protecting the network ports.
fail2ban Active Intrusion prevention system protecting SSH.
apparmor Active Mandatory Access Control system needed for security.
cron Active Schedules automatic updates (unattended-upgrades).

Critical reflection.


In the seventh phase, The nmap scan validated the work done in Week 4, proving the firewall was effective (only ports 22 and 80 open). The lynis audit made me understand that "functioning" server is not necessarily a "secure" one. Moving the Hardening Index from 60 to 61 required specific, precise changes (securing grub.cfg, password aging). I learnt that that security is not a one-time setup but a continuous process of auditing, patching, and refining.
